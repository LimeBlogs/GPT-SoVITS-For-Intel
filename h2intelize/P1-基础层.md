## 0.1 为什么是 fp32

探针实测（详见 `P0-探针结果与决策.md`）：

| 项 | fp32 | bf16 |
|---|---|---|
| 矩阵乘 | 0.35 ms | 0.37 ms |
| Conv1d | 1.97 ms | 2.02 ms |
| GAN mini step | **6.88 ms** | **9.73 ms（慢 41%）** |
| STFT | ✅ | ❌ `MKL FFT doesn't support BFloat16` |

设备属性 `has_bfloat16_conversions=False`、`has_subgroup_matrix_multiply_accumulate=False` → torch 2.7.1 在这张卡上没启用 XMX，bf16 走模拟路径。

**结论：bf16 无收益且有功能缺陷，全程 fp32。**

任何从 `GPT_SoVITS/` 下启动、且要 `import tools` 的脚本，**必须在所有 import 之前**插根路径。



### 2a. 顶部加 import

### 2b. 替换 `get_device_dtype_sm`（原 L163-182）

```python
def get_device_dtype_sm(idx: int, dev_type: str = "cuda"):
    """返回 (device, dtype, 排序键1, 排序键2)，保持原签名兼容。

    本机（A750）预期落到 fp32：
      has_bf16=False, has_xmx=False → 后面两个分支都不进。
    """
    cpu = torch.device("cpu")
    if not du.accel_available(dev_type):
        return cpu, torch.float32, 0.0, 0.0

    dev = torch.device(f"{dev_type}:{idx}")
    p = du.properties(idx, dev_type)
    mem_gb = p["total_memory_gb"]

    if dev_type == "cuda":
        rank_key = p["arch"][0] + p["arch"][1] / 10.0
        is_16_series = bool(re.search(r"16\d{2}", p["name"])) and rank_key == 7.5
    else:
        # Intel：Xe 核心数当排序键（A750 = 448EU → 4.48）
        rank_key = p["compute_units"] / 100.0
        is_16_series = False

    # 独显：total_memory 就是真实 VRAM
    min_mem = 6.0 if (dev_type == "xpu" and p.get("is_integrated")) else 4.0
    if mem_gb < min_mem:
        return cpu, torch.float32, 0.0, 0.0

    if dev_type == "xpu":
        if p["has_bf16"]:                      # 本机 False
            return dev, torch.bfloat16, rank_key, mem_gb
        if du.supports_fp16_fast(dev):         # 本机 False
            return dev, torch.float16, rank_key, mem_gb
        return dev, torch.float32, rank_key, mem_gb      # ← 本机走这里
    ...
```

> ⚠️ **不要删掉 bf16/fp16 分支**。代码要能陪其他机器，只是本机不会进。删了反而降低可移植性。

### 2c. 替换枚举循环（原 L188-209）

```python

GPU_COUNT = du.device_count(_BACKEND)

if not GPU_INFOS:

    GPU_INFOS.append(CPU_INFO)

infer_device = max(tmp, key=lambda x: (x[2], x[3]))[0]
```

## T1-4 精度迁移（`is_half` → `dtype`）

### 4a. 规则

```python
from tools import dtype_utils as dt

dtype = dt.resolve(os.environ.get("dtype") or is_half, device)   # 按设备能力降级
model = dt.apply(model, dtype)                                    # 替代 model.half()
tensor = dt.cast(tensor, dtype)                                   # 替代 tensor.half()
```

> 用 `dt.resolve()` 而不是 `dt.parse()`：`resolve` 会检查设备能力，本机自动落到 fp32。

### 4b. 改动清单

| 文件 | 行 | 原 |

| `GPT_SoVITS/TTS_infer_pack/TTS.py` | ~719 | `.half()` |
