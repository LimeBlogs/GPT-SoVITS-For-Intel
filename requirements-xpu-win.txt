# GPT-SoVITS - Intel XPU / Windows x64 / CPython 3.12
# ---------------------------------------------------------------------------
# Verified target machine (h2intelize/P0..P4):
#   Intel Arc A750 8GB (torch reports 7.8GB, CU=448), driver 1.15.37858
#   Windows 11, Python 3.12.10, torch 2.7.1+xpu
#
# Adapted from the official Windows requirements:
#   requirements-py312-win-flash_attention/requirements_py312_win_cu128_china.txt
#
# Differences vs the official CUDA list:
#   1. no flash-attn          (no Intel XPU support)
#   2. no triton-windows      (only serves flash-attn / CUDA)
#   3. no onnxruntime-gpu     (CUDA only; use onnxruntime-directml -- see P2)
#   4. keep prebuilt cp312 wheels for pyopenjtalk / jieba_fast (no MSVC needed)
#   5. add nltk               (English text frontend needs its tagger data, P4)
#
# Precision decision (h2intelize/P0 + P4, already settled):
#   torch 2.7.1 does not expose XMX on this card (has_bfloat16_conversions=False,
#   has_subgroup_matrix_multiply_accumulate=False) -> bf16 brings no speedup and
#   MKL FFT rejects bf16 STFT -> the whole project runs in fp32.
#   Nothing extra has to be installed for that; do NOT add bf16 / flash-attn
#   / ipex / torchao based "acceleration" packages.
#
# Prerequisites:
#   1) Python 3.12 x64 (the two pinned wheels at the bottom are cp312 only)
#   2) torch + torchaudio from the XPU index -- do this FIRST:
#        pip install torch==2.7.1 torchaudio==2.7.1 ^
#          --index-url https://download.pytorch.org/whl/xpu
#   3) pip install -r requirements-xpu-win.txt
#   4) nltk data for the English frontend (offline machines: copy manually):
#        python -c "import nltk; nltk.download('averaged_perceptron_tagger_eng')"
#      data dir: %APPDATA%\nltk_data\taggers\averaged_perceptron_tagger_eng
#      (the CMU pronouncing dict is bundled in GPT_SoVITS/text/cmudict*.rep,
#       so 'cmudict' does NOT need downloading)
#
# NOTE: this file is pure ASCII on purpose. pip decodes requirements files
#       using the system locale (GBK on zh-CN Windows); UTF-8 comments would
#       raise UnicodeDecodeError.
# ---------------------------------------------------------------------------
